# Activity validation client returns ApiResponse

- Scope: activity UserValidationService and one focused WebClient deserialization test.
- Root cause: pasted method declared boolean but never returned the WebClient response, had unreachable code after throw, and treated HTTP 404 as a missing user even though user-service responds HTTP 200 with data=false for that case.
- Change: make validateUser public and return the `ApiResponse<Boolean>` decoded from user-service. Preserve upstream HTTP errors; reject an empty response body.
- Verification: `mvn -q -pl activity-service -am test` passed 11/11 activity tests; focused test proved JSON `data:false` is decoded and returned with message/success intact.
