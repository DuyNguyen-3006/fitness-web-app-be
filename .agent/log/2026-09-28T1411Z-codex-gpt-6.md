# Attach Eureka to parent Maven reactor

- Scope: root and server-eureka POMs, Eureka application/config, `.idea/misc.xml`.
- Root cause: root POM omitted `server-eureka` in modules; child POM inherited Spring Boot parent directly; IntelliJ imported child POM as an independent Maven root.
- Change: register server-eureka module, inherit fitness-web parent, remove direct child POM from IntelliJ original imports. Add `@EnableEurekaServer` and standalone Eureka settings because the newly included module's context test failed with missing client transport when server annotation was absent.
- Verification: `mvn -q -pl server-eureka -am test` passed 1/1 Eureka test; `mvn -q test` passed 27/27 tests across all four reactor modules.
- Handoff: reload Maven projects in IntelliJ. If a stale top-level `server-eureka` remains, unlink that direct Maven import once, then reload the parent.
